# Tabuada Interativa com JavaScript
Um projeto de tabuada interativa desenvolvido com HTML, CSS e JavaScript. O objetivo foi criar uma ferramenta onde o usuário pode inserir um número e escolher até qual valor deseja multiplicar, praticando habilidades de front-end.

## Tecnologias Utilizadas

- HTML: para estruturação da página

- CSS: para estilização

- JavaScript: para renderização dinâmica

## Como Usar
1. Insira um número no campo de entrada.
2. Escolha o valor até o qual deseja multiplicar.
3. A tabuada será gerada automaticamente.
